## Updating the plan

The backend/data plan is a living document. When you complete an item:

1. Tick the checkbox in `BACKEND_DATA_PLAN.md`.
2. Add a dated bullet to the progress log.
3. If a decision changes, update the decisions table and say why.
4. Keep `DATA_SOURCES.md` and `data/registry/sources.yaml` in sync with any
   source change.
